# Robin 股票助手 0.7.2

- 自选页加入手机本地行情缓存：再次进入自选时先瞬间显示上一次价格、涨跌幅、量比和换手率，不再等待网络返回后才出现。
- 后台随后静默读取服务器最新行情并替换旧数据；如果服务器仍在刷新，会自动再跟进一次。
- 后端自选接口改为 stale-while-revalidate：有缓存时立即返回，东方财富慢或 502 时不再阻塞页面数秒。
- Railway 行情后端迁移到新加坡节点，缩短新西兰用户到服务器以及服务器到亚洲行情源的网络路径。
- 继续使用 0.7.0 建立的固定签名，可直接覆盖升级。

GitHub Actions 仅在固定签名与证书指纹校验通过后发布正式 APK。
