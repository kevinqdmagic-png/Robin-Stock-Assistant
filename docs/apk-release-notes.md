# Robin 股票助手 0.7.0

- 首页新增“设置 / 关于”，保留四个底部栏目不变。
- 新增“检查更新”：只有用户手动点击时才检查 GitHub 正式版本，不会自动弹窗打扰。
- 发现新版本后可在 App 内下载 APK；下载完成后调出 Android 系统更新界面，由用户确认“更新”。
- 若 GitHub Release 提供 SHA-256 digest，安装前先校验下载文件；Android 仍会执行应用签名校验。
- 股票研究正文继续隐藏冗长引用网址，后台研究来源不删除。
- 固定发布证书指纹已锁定在仓库；私钥仅通过 GitHub Actions Secrets 注入，不进入源码或构建产物。

固定签名从 0.7.0 开始作为长期升级基线。由于此前测试 APK 使用的签名无法保证与本证书一致，从旧测试版迁移到 0.7.0 可能需要最后一次重新安装；完成迁移后，后续固定签名版本可直接覆盖升级。

GitHub Actions 已配置为仅在固定签名校验通过后发布正式 APK。
