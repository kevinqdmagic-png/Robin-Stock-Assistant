# Robin 股票助手 0.7.7

- 股票研究页新增主力行为探索模型：按代码分析已完成日线中的疑似吸筹、整理尾声、放量突破、派发风险。所有分数均为未经胜率校准的统计代理，不代表主力真实账户交易。
- 低位启动和龙虎榜在 App 任务中心恢复为两个独立的 App 研究模块，从综合双标每日依赖中移除；联合任务保留历史审计记录，不再作为新执行入口。
- 新增“检查后台研究积累与学习状态”，明确历史报告和样本已归档、模型尚未自动训练，避免误以为研究归档本身就是持续学习。
- 保留每日双标的 T+2 展示期限、历史回测记录、四个底部栏目和原有行情接口。
- 本版本的低位启动/龙虎榜为 App 独立历史研究入口；要实现可靠的定时自动新报告仍需专门的执行器和数据源。

正式 APK 仅在 GitHub Actions 构建成功、固定签名和证书指纹验证通过后发布。请通过“设置 / 关于 → 检查更新”安装正式版本。
