# 当前研究执行入口（2026-11-12）

本文件集中规定执行步骤，覆盖旧文档中重复或冲突的编排；原报告、原始条件、方法版本和风控不改写。

## 每轮必须实际执行

1. 用真实UTC转换北京时间，按交易日历确定最新已完成研究日T与下一观察日D。不要把凌晨/周六启动等同于T休市。研究仅沪深股票，排除北交所。先处理最新T，再推进一项尚可补证的历史欠项；历史欠项不过期，但不能阻塞最新T。
2. 先取得最新main。如果生产API、网页抓取或某个工具失败，仍通过已连接GitHub读取本文件、`backend/data/research.json`、`task_runs.json`、`tasks.json`和原始证据。能运行终端时，克隆仓库并运行 `python scripts/prepare_task_context.py --output task-context.json`。该程序只用标准库启动、有限重试生产读回，并从仓库生成同T成果、欠项与行情状态。仓库可读意味着研究仍能推进，绝不等于APP已同步。一个访问通道失败不能推断服务宕机、账户额度耗尽或所有资料不存在。
3. 读取本模块已有详细报告全文和证据，列具体缺项。复用已验证的5,000余只同T日线档案及历史/分钟/龙虎榜资料，实际计算、横比、核查风险并补写研究。`scripts/run_scheduled_research.py`仅为局部证据兜底，不能把运行它当作完成完整研究。每轮必须有实质新增分析/数据，或有准确错误的失败报告；不能只循环审计、重复waiting、调整提示或静默退出。
4. 日线优先使用已验证BaoStock档案，其次同日独立新浪/东财全范围备份；分别核验日期、OHLCV、单位、代码类型、分母和覆盖率。不因实时源失败重新请求五千次日线。需要联网补取时先检查可用归档，再有限重试并切换独立免费源。BaoStock只用共享并发组内单连接，不并行登录；禁止用历史分钟冒充实时，或拼接来源掩盖缺失。原同花顺接口只在已验证授权接入可用时作为备选，不购买付费服务。
5. 以不可变ID原子追加完整正文、来源、原始证据和关联回执。`research.json`与`task_runs.json`一起发布；使用 `scripts/publish_linked_archives.py --base ORIGINAL_HEAD`进行ID级并发合并，只追加，不强推、不覆盖历史。其他档案按各自契约保留冻结字段与已有结果。若同ID内容冲突，停下该写入并重新读取，不能自动覆盖。
6. 执行相关回归、档案完整性和容器CI。核对准确已测试SHA的Railway终态SUCCESS，再按同T读取 `/api/daily-results?date=T`、报告全文、关联回执与 `/api/operations/delivery?date=T`。生产暂不可达只使“上线验收”受阻，不取消研究/仓库归档。分别汇报研究、归档、部署、生产读回，任何一项未验收不能称全链完成。

|模块|实际研究要求|

|volume_price|从沪深广域单日结构发现，冻结多结构广池/深池；计算量比或明确的RV5/10/20、换手、位置、突破/回踩、影线、板块同步与分时承接。检查“分歧→承接→再转强”，并保留高量滞涨、假突破、放量下跌反例。深池逐股验证，展示3–5只不能替代完整样本。|
|low_position|独立研究低位首次放量、平台突破、主升首次分歧、强势回踩、催化量价共振；量价只能支持资金行为假设，不能确认主力身份或建仓完成。旧30天样本继续追加成熟路径与失败记录，不能事后重选赢家。|
|dragon_tiger|独立读取已披露可得的龙虎榜，分开单日/多日与不同上榜原因；核对机构/股通/营业部买卖两侧、净额与集中度，避免重复累计。与量价、位置、板块、公告比较，不凭席位标签确认账户，不凭净买认定拉升。重大事实以交易所/巨潮/公司原文核验，无法取得就准确保留。|
|learning_review|先更新成熟T+1/T+2/T+5/T+10全样本与反例，再做成功/失败归因、规则变更提案和样本外方案。上涨比例与平均/中位变化分别统计，按策略版本、时段、价格基准日和有证据的市况分组；N、独立日期、盈亏幅度、缺失/不可成交与可证实MAE同时报告。没有真实成交时，胜率/净收益留空；不自动调权。|

## 输出与安全边界

- 首行：`研究交易日：YYYY-MM-DD｜发布时间：北京时间 YYYY-MM-DD HH:mm（UTC+8）`。补做保留原T与实际发布时间，周报标区间；时间不得晚于真实时刻。
- 有证据的推荐/观察股票在前部用大号标题单列名称/六位代码、准确资格、原价时点、触发/放弃条件、风险和最早合法退出日。目标为综合、09:50、14:40各两只真实观察；强弱市均研究，不能因正式信号为零就取消观察。但证据真缺失时不捏造两只或旧名单补数。正式买点与观察研究分开。
- 09:50/14:40由Railway常驻调度原时点冻结；盘后/跨日不能依据事后走势重建缺失推荐。保留原记录及缺失事实。原始价不是成交价，不把日高当已赚收益。
- 每只计划买入D，最早下一真实交易日D+1卖出；T盘后选、T+1买则最早T+2卖。给强开/平开/弱开/跌停退出情景，停牌/跌停或排队可能不成交，当日炸板不能当日止损。
- 完整研究、模拟观察、正式交易资格、实际成交、APP发布是不同状态。不把局部证据/提示更新/调度completed/HTTP200/CI通过标为全部完成；不降低既有完整研究门槛，也不以完整交易证据不足为由停止能做的研究。
- 原研究规则与版本冻结，保留亏损、未触发、不可成交、数据缺失；20–30交易日仅首轮复核节点，不是稳定盈利证明。无自动下单、借贷、融资、自动权重训练。沿用既有GitHub main及现有Railway发布授权，不新增云资源/付费源，不重复询问已授权事项。私有调度ID、完整私人提示不公开入库。
